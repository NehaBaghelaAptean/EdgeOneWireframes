/inspect-spacing

Two modes: (A) Figma Audit — validates spacing token bindings in a Figma design; (B) Code Handoff — cross-references prototype CSS against Figma values. Includes confirmed global layout rules.

inspire-compliance

/inspire-compliance

7-pass A→G audit for any Figma component: context, tokens/color, typography, spacing/layout, elevation, focus indication, component-specific rules. Outputs structured findings classified as Compliant, Minor Drift, Spec Mismatch, or Open Question.
